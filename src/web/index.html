快捷鍵對照表

      

        
H
將選取文字畫重點

        
左鍵＋右鍵
選字時按右鍵，快速畫重點

        
滑鼠側鍵
將選取文字畫重點

        
三擊文字
選取整段（工具列「¶ 整段」可把目前選取擴大成整段）

        
Ctrl+F
搜尋 PDF（支援中文與英文）

        
T
切換文字註記工具

        
Ctrl+Z／Ctrl+Y
復原／重做標註（也可用 Ctrl+Shift+Z 重做）

        
Ctrl+S
儲存含標註的 PDF

        
← / →
PageUp / PageDown
上一頁 / 下一頁

        
Home / End
第一頁 / 最後一頁

        
Ctrl＋滾輪
以游標位置縮放 PDF

        
Enter / Shift+Enter
搜尋下一筆 / 上一筆（搜尋框內）

        
Esc
關閉搜尋、註記、快捷鍵說明，或取消框選

        
Ctrl+Enter
儲存註記；助手輸入框內換行

        
?
開啟本表（輸入框外）
